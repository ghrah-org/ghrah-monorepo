# ghrah.scheme 调用说明

能力定义在 `scheme/ability/<容器>/ability.yaml`，每次调用重新扫盘（无缓存）。

## 入口总览

| 要做什么 | 调用 |
| --- | --- |
| 看有哪些能力与技能 | `scan_abilities()` |
| 看有哪些技能 | `load_skill_catalog()` |
| 读一个技能的正文 | `load_skill_catalog().read(name)` |
| 拿给模型看的工具清单 | `load_tool_list()` |
| 执行模型返回的 tool_calls | `LocalAbilityExecutor(...).execute_tool_calls(...)` |
| 两面一起看（自检用） | `scan_catalog()` |

## 1. 加载全量 ability

调用函数: `scan_abilities(pool=None) -> tuple[AbilityContainer, ...]`

调用示例:

```python
from ghrah.scheme import scan_abilities

for container in scan_abilities():
    print(container)  # 例：cluster (D:\...\scheme\ability) operations=7 skills=0
    for op in container.operations:
        print("  ", op.handler, "|", op.title)
    for skill in container.skills:
        print("  ", skill.catalog_name, "|", skill.body_path)
```

### 辅助说明

- 内置树与用户目录一起列出，按容器名排序；同名容器只有 rank 最小的那份出现（内置 rank 0，用户目录 rank 100）。
- `container` 常用成员：`name` `namespace` `version` `title` `operations` `skills` `assets` `root` `issues`，另有 `operation_count` / `skill_count` / `is_skill_only` / `is_operation_only`。
- `op.handler` 是执行与装配用的句柄；`op.full_name` 是 `ghrah.xxx` 形式的全名。
- `skill.body_path` 是**相对包目录的路径字符串**（如 `skills/SKILL.md`），读正文走第 3 节。
- 只扫盘、不 import 实现脚本，单次约 6ms。

## 2. 加载全量技能

调用函数: `load_skill_catalog(pool=None) -> SkillCatalog`

调用示例:

```python
from ghrah.scheme import load_skill_catalog

catalog = load_skill_catalog()
for skill in catalog.skills:
    print(skill.catalog_name, "|", skill.full_name, "|", skill.source, skill.rank)

print(catalog.digest)  # 技能面指纹，用于"变了没"
print(catalog.render())  # 已渲染好的目录文本，可直接塞给模型
```

### 辅助说明

- `catalog.digest` 是属性（字符串），不是方法。
- `catalog.names` 是所有技能名；`catalog.get(name)` 取单个，未命中返回 `None`。
- `catalog.issues` 记录扫描期的坏包（缺正文、容器名与目录名不符等），不影响其余技能。

## 3. 读取单个技能

调用函数: `SkillCatalog.read(name) -> SkillDocument`

调用示例:

```python
from ghrah.scheme import load_skill_catalog

catalog = load_skill_catalog()
doc = catalog.read("research")  # 目录名 / 成员键 / 容器名都能用
print(doc.name, doc.media_type, doc.path)
print(doc.content[:200])
```

### 辅助说明

- 正文路径只认定义面 `skills.<key>.body.path`，不猜、不扫目录。
- 单技能容器（成员键与容器同名）的名字是容器名；`research.research` 这种写法**不合法**。
- `SkillAbilityProvider` 是同一实现的类门面，等价写法见下。

```python
from ghrah.scheme import default_pool
from ghrah.scheme.loading.skill_provider import SkillAbilityProvider

provider = SkillAbilityProvider(default_pool())
doc = provider.read_skill("research")
```

## 4. 加载工具清单

调用函数: `load_tool_list(pool=None) -> ToolList`

调用示例:

```python
from ghrah.scheme import load_tool_list

tl = load_tool_list()
print(len(tl.tools), tl.names)  # 20 (...)

for entry in tl.entries:
    print(entry.container, entry.operation, entry.full_name)

print(tl.get("read_file"))  # {"type": "function", "function": {...}}
```

### 辅助说明

- `tl.tools` 是 OpenAI 风格的 tools 列表，可直接传给模型；`tl.entries` 带上来源容器，便于回溯。
- 没有工具面的成员（如 `conversation`）不会出现。
- 只读定义面、不 import 实现脚本，因此**不需要**造 Ability 实例。

## 5. 执行工具调用

调用函数: `LocalAbilityExecutor.execute_tool_calls(tool_calls, abilities, accumulated_data, context_manager)`

调用示例:

```python
from ghrah.chat.content import ToolCallBlock
from ghrah.scheme import LocalAbilityExecutor, create_ability

executor = LocalAbilityExecutor(agent_name="demo")
calls = [ToolCallBlock(id="call-1", name="read_file", arguments={"file_path": "README.md"})]

results = await executor.execute_tool_calls(
    tool_calls=calls,
    abilities={"read_file": create_ability("read_file")},
    accumulated_data={},
    context_manager=context_manager,
)
for item in results:
    print(item["tool_call_id"], item["outcome"])
```

### 辅助说明

- `abilities` 必须是 `{工具名: Ability 实例}`；能扫到的容器不等于能执行（见第 10 节）。
- 并发执行（`asyncio.gather`），**返回顺序不保证等于入参顺序**，请按 `tool_call_id` 回填。
- 未知工具名不抛异常，该条 `outcome` 为 `failure`。
- `context_manager` 不能为 `None`，否则立刻报 `'NoneType' object has no attribute 'get_current_state'`。
- 只跑单个能力：`await executor.execute_ability(ability, AbilityExecutionContext(tool_args=..., agent_name=...))`。

## 6. 一次看能力面与技能面

调用函数: `scan_catalog(*, pool=None) -> CatalogReport`

调用示例:

```python
from ghrah.scheme import scan_catalog

report = scan_catalog()
print("容器", len(report.containers), "handler", len(report.handlers), "技能", len(report.skills))
print("问题", report.issues)
```

### 辅助说明

- 是只读汇总（`abilities` / `handlers` / `containers` / `skills` / `roots` / `issues` + `definitions`），不写盘、不新增事实。
- 适合做启动自检或运维巡检；正常运行时按需调前面各节更省。

## 7. 换一套扫描目录

调用函数: `path_root(path, *, rank=100, source="skill-ability", required=False)` / `user_root()` / `default_pool()`

调用示例:

```python
from ghrah.scheme import path_root, scan_abilities

pool = (
    path_root(r"D:\packs\team", rank=50, source="team"),
    path_root(r"D:\packs\extra", rank=200, source="extra", required=False),
)
for container in scan_abilities(pool):
    print(container)
```

### 辅助说明

- `rank` 小者优先：同名容器只保留 rank 最小的那份，被遮蔽的记进 `issues`。
- `required=True` 的根不存在会记 issue；默认 `False` 时静默跳过。
- `user_root()` 就是 `~/.ghrah/skill-ability`；`default_pool()` 返回默认的两根。

## 8. 补写与重登记 lock

调用函数: `ensure_locks(scan)` / `relock_skill(skill)`

调用示例:

```python
from ghrah.scheme import ensure_locks, relock_skill, scan_ability_definitions

scan = scan_ability_definitions()
outcomes, issues = ensure_locks(scan)  # 只给缺 lock 的成员补写

skill = scan.skills[0]
record = relock_skill(skill)  # 强制重登记单个技能
print(record.full_name, record.content_digest[:24])
```

### 辅助说明

- 扫描与读取**从不写盘**，写 `ability.lock.yaml` 只有这两个入口。
- lock 里记 `full_name` / `provenance`（来源+指纹）/ `permission`，**不记版本**（版本权威在定义面）。
- `skill.drifted` 是扫描期算好的结论（登记值与当前值不等），读它不会重算指纹。

## 9. 写一个技能包

特性: 一个容器 = 一份 `ability.yaml` + 一份正文，**只能有一个技能**。

调用示例（目录结构）:

```
research/
├─ ability.yaml
└─ skills/
   └─ SKILL.md
```

```yaml
format: ghrah.ability-definition
schema_version: 0.1-draft
identity:
  namespace: research
  version: 0.1.0
title: Research
description: 调研类方法论
skills:
  research:
    title: Research
    description: 调研类方法论
    body:
      path: skills/SKILL.md
      media_type: text/markdown
    tags: [research]
```

### 辅助说明

- 技能正文是**纯 Markdown**，不再带 frontmatter；`name`/`description` 已迁到 `ability.yaml`。
- 成员键与容器同名时 `full_name` 收敛为容器名（`research`），不写成 `research.research`。
- 一个容器声明两个技能会被定义面直接拒绝（`ManifestValidationError`）。

## 10. 写一个 operation 包

特性: 每个 operation 一个实现脚本，约定 `<容器>/operations/<键>.py` 里**恰好一个** `Ability` 子类。

调用示例（目录结构）:

```
ability/hello/
├─ ability.yaml
├─ operations/
│  ├─ __init__.py
│  └─ greet.py
└─ __init__.py
```

```yaml
format: ghrah.ability-definition
schema_version: 0.1-draft
identity:
  namespace: ghrah
  name: hello
  version: 0.1.0
title: Hello
description: 示例能力
provider_requirements:
  local_env:
    contract: ghrah.local.v1
    required_capabilities: [request]
operations:
  greet:
    title: Greet
    description: 打个招呼
    input_schema:
      type: object
      properties:
        name: {type: string}
      required: [name]
      additionalProperties: false
    output_schema:
      type: object
      properties:
        text: {type: string}
      required: [text]
      additionalProperties: false
    errors: {}
    implementation: {provider_slot: local_env, operation: greet}
    effects: []
    resources: {}
    execution:
      mode: request
      timeout_ms: 5000
      cancellation: cooperative
      on_revoke: drain
      retry: never
skills: {}
assets: {}
```

```python
# operations/greet.py
from pydantic import BaseModel

from ghrah.scheme.execution.base import Ability, ActionResult, ActionOutcome
from ghrah.scheme.execution.context import AbilityExecutionContext

PERMISSIONS = {"fs_write": False}
HOOKS = {}
SUMMARY = "打个招呼"
TAGS = ("demo",)


class GreetInput(BaseModel):
    name: str


class GreetAbility(Ability):
    name = "greet"
    description = SUMMARY

    def bind_tool(self):
        return {
            "type": "function",
            "function": {
                "name": "hello_greet",
                "description": SUMMARY,
                "parameters": GreetInput.model_json_schema(),
            },
        }

    def get_hooks(self):
        return []

    async def execute(self, context: AbilityExecutionContext) -> ActionResult:
        payload = GreetInput.model_validate(context.tool_args)
        return ActionResult(outcome=ActionOutcome.SUCCESS, data={"text": f"hello {payload.name}"})
```

### 辅助说明

- `execution` 及其五个子字段全部必填；`mode` 目前只有 `request`，`retry` 只有 `never`。
- 容器必须放在 `ghrah.scheme.ability/<容器>/` 内：投影期按 `ghrah.scheme.ability.<容器>.operations.<键>` import 脚本，包外容器只能贡献声明与技能。
- `PERMISSIONS` / `HOOKS` / `SUMMARY` / `TAGS` 是模块级常量，投影时读取；写错名字会被静默忽略（取默认值）。
- 模型实际看到的 schema 来自实现面 `bind_tool()`；声明面的 `input_schema` 目前只用于 `load_tool_list()` 与 `list_abilities` 展示，两者不一致时以实现面为准。
